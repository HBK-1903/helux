## Yerel

## GitHub Pages

1. Bu klasörü bir repo’ya koy (`helux` veya `kullanici.github.io`).
2. Settings → Pages → Deploy from branch → `main` / `/ (root)`.
3. `.nojekyll` kalsın.
4. Paylaşım önizlemesi için `og.svg` tam URL ister; Discord bazen PNG ister — istersen 1200×630 PNG export edip `og.png` yap, HTML’de `og:image`’i ona çevir.

Sketch / `.ino` yükleme.
